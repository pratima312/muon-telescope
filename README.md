Muon-Telescope:
It is a 3 layered plastic scintillator detector. The primary unit is a triangular bar of height 17mm, width 33mm and length 528mm. 32 (16 + 16) such triangular bars are in 
contact with each other forming a ziz-zag pattern. This set of 32 triangular bars forms a plane (x or y) and then one more set of 32 bars forms one more plane (y or x) where both
planes are orthogonal to each other. These two planes consecutively considered as one layer. There are 3 such layers where the distance betweenn them is 15cm. This is the complete
set-up of the detector.
